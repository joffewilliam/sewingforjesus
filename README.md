# Sewing for Jesus

A faith-based website sharing the mission, photos, contact information, and donation opportunities for **Sewing for Jesus**.

## Overview

This is a static website built with HTML, CSS, and JavaScript.  
The site includes pages for ministry information, photos, donations, and contact.

## Site Structure

```text
sewingforjesus/
├── index.html
├── photos.html
├── donations.html
├── contact.html
├── assets/
├── scripts/
└── .github/
```

## Pages

- **Home**: `index.html`
- **Photos**: `photos.html`
- **Donations**: `donations.html`
- **Contact**: `contact.html`

## Deployment

This project is built for hosting on github pages to save the ministry money.
